# Loreforged Deck

Loreforged Deck is a fantasy-themed tabletop companion application built in Python using CustomTkinter.

The project is designed to support tabletop RPG play with tools for dice rolling, character creation, character management, and persistent character data.

## Features

- Dice roller supporting multiple die types
- Dice modifiers
- Roll animation
- Recent roll history
- Character creation
- Character saving and loading
- Character editing and deletion
- Character stats including:
  - HP
  - Armor Class
  - Initiative
  - Speed
  - Ability scores
- Inventory and spell data
- JSON-based character storage
- Custom fantasy-inspired user interface

## Built With

## Project Goals

The goal of Loreforged Deck is to create a simple desktop companion for tabletop RPG players that keeps frequently used tools in one place.

I focused on making common actions such as rolling dice and managing characters quick and easy to access while also creating a strong fantasy-themed presentation.
